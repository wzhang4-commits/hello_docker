# Hello Docker

A simple beginner Docker project that shows how to containerize and run a static website using **Docker** and **Nginx**.

## Project Overview

This project teaches students how to:

- Install Docker Desktop
- Set up a simple project folder
- Create a Dockerfile
- Build a Docker image
- Run a Docker container
- View a static website in the browser
- Stop and remove Docker resources
- Troubleshoot common Docker issues
